# HunarHub Frontend

React + Vite frontend for the HunarHub marketplace. The app includes role-based dashboards for customers, entrepreneurs, and admins.

## Scripts

```bash
npm install
npm start
npm run build
npm test
```

## Environment

Create `frontend/.env` when you need a custom API URL:

```bash
VITE_API_URL=http://localhost:5000/api
```

## Local URL

The Vite dev server runs at:

```bash
http://localhost:3000
```
